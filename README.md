# 📊 Job Market Skill Analyzer

## 📌 Project Overview

A beginner-friendly **Python project** that analyzes job postings to identify frequently requested skills in the job market.

The project demonstrates how Python data structures and programming concepts can be applied to a real-world data analysis problem.

## 🎯 Objectives

* Store and manage job posting data
* Clean and normalize skill information
* Extract and count individual skills
* Identify the most common skills
* Search jobs based on specific skills
* Find unique skills
* Save processed data to files

## 🛠️ Technologies & Concepts

**Language:** Python

**Concepts Used:**

* Lists & Dictionaries
* Sets
* Functions
* Loops & Conditional Statements
* Lambda & `filter()`
* List Comprehension
* String Manipulation
* Exception Handling
* File Handling

## 🔍 Key Insights

The analysis identifies **Python, SQL, Excel, and ML** among the frequently mentioned skills in the sample job postings.
